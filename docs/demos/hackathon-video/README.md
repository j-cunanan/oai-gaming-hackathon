# REPRO hackathon video

- [Final demo video](repro-demo.mp4): 58 seconds, 1920 × 1080, with narration.
- [Standalone narration](narration-coral.mp3): 54.816 seconds.
- [Narration script](narration.txt).

Recorded in Screen Studio on September 15, 2026, from the report-driven demo at
repository revision `2cd8d9e`. The final cut removes pauses and condenses the
recorded checkpoint playback. Narration is AI-generated using OpenAI
`gpt-4o-mini-tts` with the `coral` voice.

The walkthrough presents saved evidence for the
[data-patch persistence case](../../evidence/overnight-2026-09-15/md-12620-terra-overnight-02/README.md),
not a fresh investigation. That run received save-checkpoint guidance and remains
awaiting human review. Game footage depicts Mindustry by Anuken and contributors.

The final video and voice track are stored directly in Git (about 4.7 MB combined).
Raw recordings and the Screen Studio editing project remain local under the
ignored `output/video/` directory.
