Method, limits and source records

Three deliberately selected camera starts in one small Panda3D room. Each trial began with a fresh model conversation and no supplied solution. Controls use REPRO's existing Action schema, with a separate synthetic adapter and a maximum two-second key hold. The API uses GPT-6 Astra through Responses, image input, function calling and Structured Outputs. The scorer's coordinates and world state never enter the model input.

After the adaptive run, the exact executed action sequence runs five times on fresh buggy state and five times on the hand-corrected reference. A separate verification pass uses repro.agents.oracle.verify_sequence on four ordered screenshots from each variant. Those model judgments are separate calls, not independent ground truth.

The 3/3 result is a small curated feasibility test, not a 3D-game success-rate estimate. This is one intentionally seeded bug, not three newly discovered bugs. These trials are excluded from the Mindustry Impact page. No complete REPRO game-adapter, source-localization or AI-patch workflow was tested here.
